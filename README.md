## Dataset

The Netflix Movies and TV Shows dataset was sourced from Kaggle.

- **Source:** [Netflix Movies and TV Shows Dataset on Kaggle](https://www.kaggle.com/datasets/shivamb/netflix-shows)
- **Format:** CSV
- **Description:** Contains information about Netflix titles, including type, title, director, cast, country, release year, rating, duration, and genre.

The dataset is not included in this repository. Download it from the source above and place `netflix_titles.csv` in the same directory as the Jupyter Notebook before running the analysis.
